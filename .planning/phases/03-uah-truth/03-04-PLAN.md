<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| scheduler → NBU | Cron-triggered outbound HTTP; a failure must not crash the app or block Mono import. |
| lifespan → httpx client | An unclosed NBU AsyncClient escalates to a hard failure under filterwarnings=["error"]. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-12 | DoS (availability) | fx bootstrap blocking startup | mitigate | Bootstrap is fire-and-forget via `asyncio.create_task` (D-07); lifespan yields immediately; health check responsive. |
| T-03-13 | DoS (self-inflicted) | NBU failure crashing app | mitigate | Per-currency try/except in fx_tick + bootstrap; failure → log + `last_error`, retry next tick (D-08/D-16); never touches scheduler_state. |
| T-03-14 | Tampering | cron wrong-time firing (tzdata/DST) | mitigate | `CronTrigger(timezone=ZoneInfo("Europe/Kyiv"))` (Pitfall 5); tzdata guard (A4); `test_fx_cron_dst.py` asserts fire time across DST. |
| T-03-15 | Resource leak | unclosed NBU client | mitigate | `await nbu_importer.aclose()` in lifespan finally (CR-01); `test_health.py`/`test_no_auth.py` run under filterwarnings=["error"]. |
| T-03-16 | Tampering (SSRF) | NBU base URL | mitigate | Hardcoded constant / defaulted setting; no user input in the URL (V9 / OPS-05 egress). |
| T-03-SC | Tampering | npm/pip/cargo installs | accept | No new runtime package except the optional unconditional `tzdata` (already in uv.lock, win32-marked); RESEARCH § Package Legitimacy Audit confirms zero new external install surface. |
</threat_model>
