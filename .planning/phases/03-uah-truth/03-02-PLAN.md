NBU exchange_site response shape (RESEARCH, verified live 2026-05-30) — array of objects:
- `exchangedate`: "08.05.2026" (dd.mm.yyyy — parse with `%d.%m.%Y`)
- `cc`: "USD" (ISO alpha — use for FxRateRow.currency)
- `rate`: 43.8033 (mid-rate — read as Decimal via `parse_float=Decimal`)
- `rate_per_unit`: equals `rate` when `units==1`; use defensively if units != 1
- `r030`, `calcdate`, `units`, `group`, `special`: not load-bearing for the row.
- Empty/unknown result: HTTP 200 with body `[]`.
